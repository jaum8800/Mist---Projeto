Mist

Aplicativo de organização pessoal e finanças focado em uso mobile e desktop.

Sobre o projeto

O Mist é um painel integrado para centralizar tarefas diárias, controle financeiro e hábitos em um só lugar. O objetivo é substituir múltiplos aplicativos por uma única interface simples.

Funcionalidades planejadas

- Autenticação de usuários (Firebase Auth)
- Calendário para eventos e datas importantes
- Painel financeiro com saldo geral e divisão por bancos
- Bloco de notas e listas de tarefas
- Integração com mapa para salvar localizações
- Registro de rotina de treinos e alimentação

Tecnologias

- HTML5 / CSS3 / JavaScript
- Firebase (Authentication e Firestore)
